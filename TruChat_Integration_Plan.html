TruChat Specification & Integration Plan

Complete Technical Blueprint for Django Backend & React Frontend Integration

1. System Architecture Overview

The system comprises a Django REST Framework backend running on port 8000 and a Vite + React frontend running on port 5173, styled according to the PDF Editorial design specification.

2. Available API Endpoints

2.1 User & Auth App (/api/user/)

Endpoint Method Auth Payload Description
/api/user/register/ POST No { email, username, password } Register user account
/api/user/login/ POST No { email, password } Issue access & refresh JWT
/api/user/logout/ POST Bearer { refresh_token } Blacklist refresh token
/api/user/profile/ GET Bearer None Fetch user profile details
/api/user/profile/update/ PATCH Bearer { username?, email? } Update profile details
/api/user/change-password/ POST Bearer { old_password, new_password } Change user password
/api/user/forgot-password/ POST No { email } Trigger password reset email
/api/user/reset-password/ POST No { uid, token, new_password } Complete password reset
/api/user/delete-account/ DELETE Bearer { password } Delete user account

2.2 Fact-Checking App (/api/data/)

Endpoint Method Auth Payload Description
/api/data/claims/check/ POST Optional { "claim_text": "..." } Execute fact-checking pipeline and return verdict report

3. Key Integration Tasks

  • Clean Outdated Backend Code: Remove duplicate TruChat/app/ directory.
  • Configure CORS: Update app/.env to permit CORS origin http://localhost:5173.
  • Implement Auth Layer: Set up Axios interceptors and React Auth Context in TruChat/src/.
  • Build Editorial UI Layout: Align pages and components against PDF design specifications.
